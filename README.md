# CLI Assistant

CLI Assistant is a professional Windows Forms application designed to streamline the process of generating and publishing content to Facebook Groups. By leveraging Google's Gemini AI, the tool transforms raw project descriptions into polished, engaging social media posts.

## Key Features

*   **AI-Powered Content Refinement**: Automatically rewrites and formats raw text into professional Arabic posts using the Gemini API, incorporating appropriate emojis and structured paragraphs.
*   **Direct Facebook Integration**: Publishes generated content directly to specific Facebook Groups via the Facebook Graph API using secure access tokens.
*   **Dynamic Project Linking**: Includes dedicated logic to seamlessly integrate and highlight GitHub project links within the final post for developer outreach.

## Technical Stack

*   **Language**: C#
*   **Framework**: .NET Framework / Windows Forms
*   **Integrations**: Google Generative AI (Gemini SDK) and Facebook Graph API v19.0
